# Bestiolins

Choisis ta bestiole, descends dans la crypte, bats les monstres et remplis ton Bestiaire.

Joue ici : https://vorpiikx99.github.io/Bestiolins/

Le jeu marche aussi sans internet une fois ouvert, et peut s'ajouter à l'écran d'accueil du téléphone.

Jouer à deux : touche « Jouer à deux ». Les deux téléphones se connectent directement l'un à l'autre (il faut internet sur les deux).
